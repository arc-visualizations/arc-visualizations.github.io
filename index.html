ARC Behavioral Data Visualizations

The Abstraction and Reasoning Corpus (ARC) is a challenging program induction dataset that was proposed by Chollet (2019). Here, we report a comprehensive set of results collected from a two-phase behavioral study of humans solving ARC tasks from the training set and from the evaluation set.
